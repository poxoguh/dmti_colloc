## Представление данных

> Все модули работают с одними и теми же структурами — если ты понял их, остальное встанет на место.

---

### Натуральное число — `Natural`

**Тип:** `tuple[int, list[int]]` — пара `(n, A)`

| Поле | Тип | Смысл |
|---|---|---|
| `n` | `int` | индекс старшей значащей цифры (= длина − 1) |
| `A` | `list[int]` | цифры числа, **младшая цифра первая** |

Цифры хранятся в **обратном порядке** — это упрощает сложение с переносом:
`A[0]` — единицы, `A[1]` — десятки, `A[2]` — сотни и т.д.

```python
# Число 0
(0, [0])

# Число 7
(0, [7])

# Число 123  →  цифры в обратном порядке: 3, 2, 1
(2, [3, 2, 1])   # A[0]=3, A[1]=2, A[2]=1

# Число 10050
(4, [0, 5, 0, 0, 1])   # A[0]=0, A[1]=5, A[2]=0, A[3]=0, A[4]=1
```

**Как распаковать Natural в коде функции:**
```python
def ADD_NN_N(a: Natural, b: Natural) -> Natural:
    n_a, A = a   # n_a — старший индекс, A — список цифр
    n_b, B = b
    ...
```

**Важные соглашения:**
- Ведущих нулей нет: для числа 23 верно `(1, [3, 2])`, а не `(2, [3, 2, 0])`
- Исключение: ноль — `(0, [0])`, не пустой список
- `n` всегда равен `len(A) - 1`

### Целое число — `Integer`

**Тип:** `tuple[int, int, list[int]]` — тройка `(sign, n, A)`

| Поле | Тип | Смысл |
|---|---|---|
| `sign` | `int` | знак: `0` = плюс или ноль, `1` = минус |
| `n` | `int` | индекс старшей цифры (как в Natural) |
| `A` | `list[int]` | цифры числа, младшая первая (как в Natural) |

```python
# Число 0  →  знак всегда 0 для нуля!
(0, 0, [0])

# Число +123
(0, 2, [3, 2, 1])

# Число -123
(1, 2, [3, 2, 1])

# Число -1
(1, 0, [1])
```

**Как распаковать Integer в коде:**
```python
def ABS_Z_N(a: Integer) -> Natural:
    sign, n, A = a
    return (n, A)   # просто убираем знак — получаем Natural
```

**Важные соглашения:**
- Ноль всегда `sign = 0`, никогда `sign = 1`
- Модульная часть `(n, A)` — это ровно тот же Natural

### Рациональное число — `Rational`

**Тип:** `tuple[Integer, Natural]` — пара `(числитель, знаменатель)`

| Поле | Тип | Смысл |
|---|---|---|
| первый элемент | `Integer` | числитель (может быть отрицательным) |
| второй элемент | `Natural` | знаменатель (всегда строго > 0) |

Знак дроби хранится **в числителе**. Знаменатель всегда положителен.

```python
# Дробь 1/2
((0, 0, [1]),  (0, [2]))

# Дробь -3/4
((1, 0, [3]),  (0, [4]))

# Целое число 5, записанное как дробь 5/1
((0, 0, [5]),  (0, [1]))

# Дробь 22/7
((0, 1, [2, 2]),  (0, [7]))
```

**Как распаковать Rational в коде:**
```python
def ADD_QQ_Q(a: Rational, b: Rational) -> Rational:
    num_a, den_a = a   # num_a: Integer, den_a: Natural
    num_b, den_b = b
    ...
```

**Важные соглашения:**
- Знаменатель никогда не равен нулю
- Дробь не обязана быть сокращённой внутри вычислений —
  сокращение делает отдельная функция `RED_Q_Q`

---

### Многочлен — `Polynomial`

**Тип:** `tuple[int, list[Rational]]` — пара `(m, C)`

| Поле | Тип | Смысл |
|---|---|---|
| `m` | `int` | степень многочлена |
| `C` | `list[Rational]` | коэффициенты: **`C[0]` — при x⁰**, `C[1]` — при x¹, ... |

```python
# Многочлен 2x + 3  →  степень 1
(1, [
    ((0, 0, [3]), (0, [1])),   # 3/1 при x^0
    ((0, 0, [2]), (0, [1])),   # 2/1 при x^1
])

# Многочлен 3/2·x² + 0·x + 1/4  →  степень 2
(2, [
    ((0, 0, [1]), (0, [4])),   # 1/4 при x^0
    ((0, 0, [0]), (0, [1])),   # 0/1 при x^1
    ((0, 0, [3]), (0, [2])),   # 3/2 при x^2
])
```

**Как распаковать Polynomial в коде:**
```python
def DEG_P_N(a: Polynomial) -> int:
    m, C = a
    return m

def LED_P_Q(a: Polynomial) -> Rational:
    m, C = a
    return C[m]   # старший коэффициент — последний элемент
```

**Важные соглашения:**
- `len(C)` всегда равно `m + 1`
- Ведущий коэффициент `C[m]` никогда не равен нулю (кроме нулевого многочлена)
- Нулевой многочлен: `m = 0`, `C[0]` = рациональный ноль `((0,0,[0]), (0,[1]))`

---

### Шпаргалка — все типы рядом

```python
Natural    = (n: int,            A: list[int])
Integer    = (sign: int,  n: int, A: list[int])
Rational   = (num: Integer,      den: Natural)
Polynomial = (m: int,            C: list[Rational])
```

### Граф зависимостей — порядок разработки

```
Natural         ← разрабатывается первым, все зависят от него
   ↓
Integer         ← использует Natural
   ↓
Rational        ← использует Integer и Natural
   ↓
Polynomial      ← использует Rational, Integer, Natural
```
